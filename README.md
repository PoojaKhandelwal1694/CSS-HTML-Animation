# CSS & HTML Animation 

This project showcases various animation effects created using HTML and CSS. It demonstrates how CSS keyframes can be used to create interactive and visually appealing animations such as color changes, movement, rotation, scaling, fading, loading spinners, bouncing balls, and moving shapes.

## Features

* Color-changing animation
* Up and down movement animation
* Rotation animation
* Pulse (scale) effect
* Fade in/out effect
* Loading spinner animation
* Moving square animation
* Bouncing ball animation
* Pure HTML and CSS implementation

## Technologies Used

* HTML
* CSS
* CSS Keyframe Animations


## Animation Examples Included

### 1. Color Change Animation

A box smoothly changes colors using CSS keyframes.

### 2. Movement Animation

A box moves vertically up and down repeatedly.

### 3. Rotation Animation

A box rotates 360 degrees continuously.

### 4. Pulse Animation

A scaling effect that enlarges and shrinks the box.

### 5. Fade Animation

A box fades in and out by changing opacity.

### 6. Loading Spinner

A circular loading animation created using borders and rotation.

### 7. Moving Square Animation

A square moves around the edges of a rectangular path.

### 8. Bouncing Ball Animation

Multiple colored balls create a wave-like bouncing effect.

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. Observe the different animation effects in action.
